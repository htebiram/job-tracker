# JobTracker API

ASP.NET Core Web API demonstrating:

- Clean Architecture
- RESTful API design
- Entity Framework Core
- SQL Server
- Structured logging
- Validation
- Unit testing
- Integration testing

## Architecture

- JobTracker.Api
- JobTracker.Application
- JobTracker.Domain
- JobTracker.Infrastructure

## Getting started

1. Clone the repository.
2. Update the connection string.
3. Apply migrations.
4. Configure Auth0.
5. Run the API.
